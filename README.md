# EarCraft — Music Ear Trainer

A fully client-side music ear training web app. No build step, no dependencies — pure HTML/CSS/JS + Tone.js.

🎵 **Live demo:** https://nnigmat.github.io/ear-trainer/

## Features
- Identify and construct intervals by ear (melodic & harmonic playback)
- Identify and build chord qualities (Major, Minor, Aug, Dim, 7th)
- Interactive piano keyboard (C3–C5) and guitar fretboard (standard tuning, 12 frets)
- Realistic audio synthesis via Tone.js
- Score tracking with streak counter

## Tech
Vanilla HTML · CSS · JavaScript · Tone.js Web Audio API · GitHub Pages
